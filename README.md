## 📖 Описание
Book Tracker — десктопное GUI-приложение для учёта прочитанных книг. 
Позволяет добавлять книги, фильтровать их по жанру и объёму, 
а также сохранять и загружать данные в формате JSON. 
Приложение написано на чистом Python без сторонних зависимостей.

## 🛠 Возможности проекта
- **🖥 Графический интерфейс** — десктопное приложение на стандартном модуле `tkinter` (не требует установки сторонних библиотек).
- **➕ Добавление записей** — удобная форма с полями: название книги, автор, жанр, количество страниц.
- **✅ Валидация ввода** 
  - Все поля обязательны для заполнения.
  - Количество страниц проверяется на целочисленность и положительное значение.
  - При ошибках выводятся понятные всплывающие уведомления.
- **🔍 Двухуровневая фильтрация**
  - По жанру (точное совпадение, регистронезависимо).
  - По объёму: отображение только тех книг, у которых количество страниц больше заданного числа (например, `> 200`).
- **🔄 Сброс фильтров** — кнопка мгновенного возврата к полному списку без перезагрузки данных.
- **💾 Сохранение и загрузка JSON** 
  - Экспорт текущего списка в файл `books.json` с сохранением кириллицы (`UTF-8`).
  - Импорт данных из файла с автоматическим заполнением таблицы.
  - Безопасная обработка отсутствующих или повреждённых файлов.
- **📋 Табличное представление** — скроллируемый `Treeview` с фиксированными заголовками и адаптивным размером колонок.
- **🌍 Кроссплатформенность** — корректная работа на Windows, macOS и Linux.
- **📦 Git-готовая структура** — включён рекомендованный `.gitignore` для чистого коммита и лёгкого деплоя на GitHub.
